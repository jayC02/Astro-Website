# scotlandepc.com

Static site for Scotland EPC (domestic EPCs and legionella risk assessments), hosted on Vercel.
It shares its design system with fireriskscotland.com.

- Pages are generated by `python scripts/build.py` from the templates in `scripts/parts.py` and the
  content in `scripts/build.py` and `scripts/content/`. Edit there and re-run the build; editing the
  HTML directly works, but the next build overwrites it. `scripts/` is not deployed.
- `api/quote.js` is the Vercel function behind the quote form. It sends emails through Resend.
  Needs `RESEND_API_KEY` in Vercel. Quote requests go to jay@scottishenergyservices.co.uk unless
  `QUOTE_TO_EMAIL` is set. Optional: `QUOTE_FROM_EMAIL`, `QUOTE_NOTIFY_FROM`.
- Assets in `/assets/` are cached for a year. When you change `site.css` or `site.js`, bump `V` in
  `scripts/parts.py` and rebuild.
- Prices: EPC from £70 (flat), £75 (maisonette), £80 (bungalow), £85 (house); legionella from £65;
  both £120; all plus VAT.
